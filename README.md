📖 Overview
In the modern cybersecurity landscape, organizations face increasingly sophisticated cyber threats that demand robust detection and response capabilities. Security Operations Centers (SOCs) serve as the frontline defense, continuously monitoring, analyzing, and responding to security incidents. At the heart of every effective SOC lies a Security Information and Event Management (SIEM) system—a centralized platform that aggregates, correlates, and analyzes log data from across the enterprise infrastructure.

Splunk Enterprise stands as one of the industry's leading SIEM platforms, offering powerful log management, real-time search, advanced analytics, and intuitive visualization capabilities. Its versatility makes it the platform of choice for security analysts, threat hunters, and incident responders worldwide.

This graduation thesis presents a comprehensive implementation of a log analysis and threat detection system built on Splunk Enterprise Free. The project leverages the BOTS v3 (Boss of the SOC) dataset—a sophisticated, realistic attack simulation developed by Splunk that mirrors complex cyber attack scenarios in hybrid cloud environments.

Key Features
🔍 Log Aggregation & Normalization — Centralized collection and parsing of diverse log sources

🎯 Threat Detection Use Cases — 7+ detection rules covering the complete attack lifecycle

🗺️ MITRE ATT&CK Mapping — Contextual alignment of threats with industry-standard framework

📊 Interactive Dashboards — Visual representation of security metrics and attack patterns

📋 Incident Investigation — Comprehensive simulation of SOC analyst workflows
